# AI website builder landscape 2026 — research

Scan for ProjectSites.dev ("we don't sell websites, we deliver them": search business → sign in → AI site hosted+SSL'd+live <15min). Two camps: **SMB site-delivery** (Durable/Wix/Squarespace/GoDaddy/Hocoos/10Web — our lane) and **vibe-coding app builders** (Lovable/v0/Bolt/Base44/Replit — our editor's lane). Tag [HIGH]/[MED].

## Players (name — what — standout feature)
- **Durable** — 3-page SMB site from name+city+industry in ~30-47s — fastest TTFR + bundled CRM/invoicing/analytics "business OS", auto-build from Google Business Profile.
- **Wix (Harmony/Aria)** — ChatGPT-powered prompt→site, retired ADI Nov-2024 — 15+ AI tools; hybrid AI-chat + pixel-level drag-drop; AI section/layout switcher.
- **Squarespace (Blueprint AI)** — 5-step guided interview → design-forward starter (~4min) — "Design Intelligence" suite: brand voice engine applied to all generated copy.
- **Framer (Workshop/Wireframer)** — design-led; Wireframer ships responsive multi-page in <60s — Workshop AI vibe-codes on-brand custom components (Claude 4.5); MCP bring-your-own-LLM.
- **Webflow (AI Site Builder/AEO)** — higher-ceiling CMS + AI Assistant — **native site-wide AEO audits** (answer-engine optimization) — the clearest AI-search moat in the field.
- **Hostinger Horizons** — text/voice/image → real **React+Vite** app w/ Supabase DB+auth in ~60s — credit-based; hosting+SSL+domain+email bundled; dynamic apps not just static.
- **GoDaddy Airo** — idea→live business: hosting+payments+auth+deploy+logo in one — ecosystem bundle (Getty images, phone support, domains); static-marketing leaning.
- **Lovable** — non-tech founders → full-stack MVP — deep Supabase provisioning ("add auth" wires tables+RLS); Chat-Mode agent; pushes to **your GitHub repo** (portable).
- **v0 (Vercel)** — production-grade Next.js/shadcn UI + full-stack — **Feb-2026 Git/PR workflow** (only builder fitting pro code review); agentic research/debug/plan.
- **Bolt.new (StackBlitz)** — code-first in-browser WebContainers (real Node in tab) — V2 agentic multi-file planning + auto-fix build errors; Figma import; Bolt Cloud (DB/auth/host).
- **Base44 (Wix, acq. $80M)** — no-code prompt→full-stack on managed infra (Postgres/auth/storage) — 2M+ users; zero code shown; iterate by chat (⚠ 2025 auth-bypass CVE).
- **Replit Agent 3** — autonomous long-run agent: plans→writes→**tests in real browser**→self-fixes→deploys — full IDE (files/terminal/DB/logs); Design Mode + Fast Build.
- **10Web** — AI WordPress: describe→production WP site ~10min, **guaranteed 90+ PageSpeed** — 10-agent "Agentic Website Builder" (brief→design→build→SEO→mgmt); site cloning.
- **Hocoos** — question-wizard (not prompt) → **3 demo styles** to pick in seconds — fastest observed pick-a-look flow; beginner-first.
- **Relume** — planning-only: AI sitemap→wireframe→section copy for Webflow/Figma — upstream design-ops, not a host.
- **Newcomers/pattern (Readdy, Landbase, Butternut, RationalGo)** — "agent that never sleeps": build **then continuously** optimize SEO/CWV/AEO post-launch vs one-shot generate-and-stop.

## Killer features we should adopt [prioritized]
- **[HIGH] Native AEO/GEO layer** (Webflow proves) — auto schema markup, direct-answer blocks, citation tracking across ChatGPT/Perplexity/Gemini/Claude/AI-Overviews. Gartner: search −25% by 2026; this is THE 2026 battleground. We already do JSON-LD — extend to answer-blocks + an "AI-search visibility" admin panel.
- **[HIGH] Auto-build from Google Business Profile** (Durable proves) — pull hours/photos/reviews/services from GBP so the owner types almost nothing. Deepens our "search your business → done" promise; kills the empty-prompt→generic-site problem every reviewer flags.
- **[HIGH] Continuous/agentic post-launch optimization** (10Web/Readdy/Landbase) — a background agent that keeps improving SEO/CWV/AEO/copy after go-live, not a one-shot build. Fits our WfP + Workflows + admin "self-diagnosing" stance; reframes site as growing asset.
- **[HIGH] Business-OS bundle** (Durable proves) — CRM + invoicing + analytics + marketing beside the site. Our app-catalog is the seed; surface a "run your business" hub so we sell outcomes not pages.
- **[MED] Brand-voice engine** (Squarespace proves) — derive a persistent tone from the business, apply to ALL generated + future copy (blog/email/sections) for consistency.
- **[MED] "3 demo styles to pick"** (Hocoos proves) — offer 2-3 distinct AI directions at first result, not one, so the owner chooses (agency-feel, higher satisfaction).
- **[MED] Own-your-code / GitHub export** (Lovable proves) — portability as trust signal for owners wary of lock-in; aligns w/ our deliverable-portability memory.
- **[MED] Guaranteed performance SLA** (10Web's 90+ PageSpeed) — publish a CWV/Lighthouse guarantee as a marketing claim; we already gate on it — advertise it.
- **[MED] Real-browser self-test + auto-heal** (Replit Agent 3) — agent navigates the generated site, finds broken states, fixes before delivery. Mirrors our completeness-checker/visual-qa loop — make it visible to the owner.
- **[MED] Voice/image input** (Hostinger) — describe by voice or upload a photo/existing-site screenshot to seed generation.
- **[MED] Dynamic apps not just static** (Hostinger/Base44/Lovable) — per-site D1 + Functions (WfP) already give us this; package as "add a booking/CRM/portal" beyond brochureware.

## Onboarding / TTFR / conversion tactics worth copying
- **Sub-60s first result is table stakes** — Durable 47s, Hostinger ~60s, Framer <60s. Our <15min is generous; make FIRST *preview* land in <60s, publish later.
- **Ask ≤3 questions** (Hostinger 3-click, Durable name/city/industry) — minimize input; infer the rest (we can via search + GBP). Every extra field costs conversion.
- **Free preview BEFORE signup/pay** (Durable/Lovable "build & share preview free") — show the generated site, gate only publish/custom-domain behind payment. Reduces first-try friction.
- **Guided interview beats blank prompt** (Squarespace/Hocoos/Blueprint) — vague prompts → generic sites (every reviewer's #1 complaint). Structured Q&A or search-seeded context yields better output than a lone text box.
- **Pick-a-direction moment** (Hocoos 3 styles) — a choice early raises perceived quality + ownership.
- **Custom domain in seconds, bundled free** (Durable/Hostinger) — we already sell CF-native domains; make attach a 1-click in the same flow.
- **Post-build "visibility/health checks"** (Squarespace search checks, Wix SEO assistant) — immediately show SEO/AEO score + fixes after generation → upsell + trust.

## Positioning + moat ideas for a CF-native delivery platform
- **"Delivered, not DIY"** — everyone else hands you an *editor + 80% site you must finish* (the universal reviewer gripe: "AI does structure not strategy; you rewrite the copy"). Our wedge: a genuinely *finished, hosted, live* site with real researched content — beat-the-source, not fill-the-template.
- **CF-native = the moat**: global edge, per-site D1/R2/KV/Functions isolation, WfP tenancy, sub-second TTFB, built-in analytics — competitors bolt on Supabase/Netlify/GCP; we own the whole plane at edge cost. Sell it as speed + isolation + one bill.
- **AI-search-first delivery** — ship every site AEO/GEO-ready by default (schema, answer-blocks, llms.txt, citation-tracking). Turn "will AI cite my business?" into our headline promise before rivals default it.
- **Real business content, cited** — competitors ship stock images + generic copy. Our research-saturation + citations pipeline is a defensible quality gap; make "we researched your actual business" the demo moment.
- **Beat them = (a) truly-live finished site in <60s preview / <15min published, (b) content that beats the source not lorem-grade filler, (c) AEO-ready by default, (d) business-OS + dynamic apps via app-catalog + WfP, (e) continuous post-launch optimization agent, (f) one CF bill, edge-fast, isolated per site.** No single competitor holds all six — Durable owns speed+OS but static/generic; Webflow owns AEO+ceiling but slow+DIY; Hostinger/Lovable own dynamic but developer-sandbox feel.
