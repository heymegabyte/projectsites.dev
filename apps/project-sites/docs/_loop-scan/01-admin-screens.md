# Admin dashboard — scan + recommendations

Scope: `apps/project-sites/frontend/src/app/**` (Angular 21 Spartan-UI admin SPA). ~40 `/admin/*` routes + ~90 section components. Shell = `admin.component.ts` (persistent bolt iframe + `AdminStateService`). `/admin` = Getting-Started dashboard hub (`sections/dashboard.component.ts`, 1619 lines).

## Sections inventory (section — what it does — top recs [HIGH/MED])

- **Dashboard `/admin` (`dashboard.component.ts`)** — Getting-Started hub: purpose-grouped guide to every section + recent-sites widgets + status buckets (Needs-attention/Live/Building/Draft). — [HIGH] it is a static section-catalog, not a cockpit: add live KPI tiles (sites live, builds running, form leads today, MRR) up top. [HIGH] "Needs attention" bucket should be actionable (one-click fix/retry per row), not just a filter. [MED] AI "what should I do next?" strip that reads readiness + analytics + billing state. [MED] no `mini-empty` usage — brand-new user sees a wall of links, not one obvious CTA.
- **Editor `/admin/editor` (`editor.component.ts`)** — thin shell; bolt.diy iframe lives in `AdminComponent`. — [HIGH] cold-boot veil needs contextual copy + progress, not a spinner. [MED] surface "open in new tab" + last-saved indicator.
- **Sites hub + detail `/admin/sites/:id` (`site-detail.component.ts`, 1459 ln)** — per-site tabs: Logs / Snapshots+Rollback / Data / Schema / Integrations. — [HIGH] `/admin/sites` bare redirects to dashboard — add a real filterable/sortable sites grid (thumbnail, status, domain, last-build). [HIGH] per-site tabs (`site-data-browser` 88K, `site-schema-browser`) are deep — add a site "Doctor" summary tab surfacing readiness + broken assets inline. [MED] site cards need live status dot (real-time, no refresh).
- **Analytics `/admin/analytics` (`analytics.component.ts`, 134K!)** — tabbed traffic + Live Events + Social; ~40 sub-cards (web-vitals, funnels, referrers, scroll-depth…). — [HIGH] 134K god-component — split per tab into lazy `@defer` chunks (perf + maintainability). [HIGH] verify-against-source-of-truth: reconcile displayed counts vs D1 `visitor_events` (prior lying-empty incident). [MED] add AI "insight of the day" derived from the 40 cards. [MED] date-range picker + compare-to-prior-period across all cards.
- **Billing `/admin/billing` (`billing.component.ts`, 2790 ln / 138K)** — Stripe checkout, subscription, entitlements, usage. — [HIGH] split god-component; move plan-compare into a reusable card. [HIGH] entitlement-locked controls must show reason + upgrade CTA (never a dead button). [MED] usage gauges with projected overage + "you'll hit limit in N days".
- **Settings `/admin/settings` (`settings.component.ts`, 1597 ln)** — project-scoped tabs: General / Domains / MCP / AI-Chat / Webhooks / API-Tokens / Team. — [HIGH] tabs are heavy + folded-in (domains, api-tokens, mcp, ai-chat, webhooks) — each deserves lazy load + its own H1 for a11y. [MED] "which project am I editing?" banner is easy to miss — make the scope pill prominent. [MED] search across all settings (Cmd+K into a setting).
- **User settings `/admin/user` (`user-settings.component.ts`, 83K)** — user-level theme + personal API keys. — [MED] split from 83K; [MED] add profile/avatar + notification preferences here.
- **Domains (`domains.component.ts` 47K + `domain-manager` 38K + `domain-stack` 18K)** — vanity domain search/purchase, custom-hostname attach, DNS→SSL→email-auth→GSC wizard. — [HIGH] attach UX re-prompted thrice historically — needs real-browser-verified happy path + inline DNS status (real-time). [MED] one-click "buy + attach + verify" express path. [MED] map panel per address (google-maps-panels rule).
- **Forms `/admin/forms` (`forms.component.ts`, 1801 ln)** — form-submission inbox per site + analytics cards. — [HIGH] inbox needs bulk actions (mark-read, export, spam) + keyboard nav ↑↓enter. [MED] reply-via-email inline; [MED] submission→CRM/notification wiring surfaced.
- **Voice `/admin/voice` (`voice.component.ts`)** — phone numbers, call+SMS timeline, mic test, agent-prompt editor, MCP attach. — [MED] empty state when no number → one-click provision. [MED] live call indicator (real-time).
- **Social `/admin/social` (`social.component.ts`, 2649 ln / 131K)** — composer + scheduler for 11 networks + calendar + analytics. — [HIGH] 3267-line god-component over style budget — split into sub-sections (noted in frontend CLAUDE.md). [MED] AI caption/hashtag generation per network. [MED] drag-drop calendar reschedule.
- **Apps (`apps.component.ts` 42K + `apps-detail` 82K + `apps-instances` 85K)** — catalog of self-hostable apps → deploy to CF Containers → instances. — [HIGH] instance detail (85K) needs live status/logs stream (real-time, no refresh button). [MED] catalog needs "recommended for your site" AI ranking. [MED] one-click deploy with sane defaults (zero-config).
- **Snapshots (`snapshots.component.ts` 109K + `snapshots-diff` 18K)** — version snapshots + rollback + side-by-side diff. — [HIGH] 109K — split; [MED] visual (screenshot) diff alongside code diff. [MED] one-click "restore this version" with undo.

- **Deliverability `/admin/deliverability` (19K)** — SPF/DKIM/DMARC check + fixes per site. — [MED] one-click apply DNS fixes (reuse domain-stack). [MED] real-time re-check.
- **Team `/admin/team` (16K)** — members + invites (Better Auth org), seat usage. — [MED] role editor inline; [MED] seat-limit → upgrade CTA.
- **Leads `/admin/leads` (32K, sysAdmin)** — Places no-website scan → scored leads → outreach claim links. — [MED] AI-drafted outreach message per channel. [MED] bulk claim-link mint.

## Cross-cutting admin recs (nav, empty states, keyboard, real-time)

- [HIGH] **Real-time everywhere / kill refresh buttons** — audit every data surface (apps instances, domains DNS/SSL, logs, analytics, inspectors) for manual Refresh/Reconcile controls; replace with visibility-aware poll / SSE per `real-time-data-no-manual-refresh` (Resources tab already flagged by Brian). `AdminStateService` polls sites/analytics; extend the pattern.
- [HIGH] **Empty states as launchpads** — most sections show "no data" text; every empty state should be the one button that creates the first result (`mini-empty` exists — wire it into voice, forms, leads, apps, domains, site-features).
- [HIGH] **God-component split (perf + a11y)** — `analytics` 134K, `billing` 138K, `social` 131K, `snapshots` 109K, `settings`/`site-data-browser` ~88K each. Lazy `@defer` per tab; each folded tab needs its own single `<h1>` (axe-blind H1 gaps are a known class).
- [MED] **Keyboard nav on every list** — forms inbox, leads, logs, sites grid: ↑↓ to move, Enter to open, Esc to close; every clickable action gets a shortcut + `?` legend (shortcuts-overlay exists).
- [MED] **Never a dead/doomed control** — entitlement/seat/flag-locked buttons must show reason + fix inline (billing, site-features, team), per `action-button-must-gate-on-server-precondition`.
- [MED] **Undo on every mutation** — toast is action-armed; ensure delete/rollback/toggle all offer Undo (`ToastService` supports it).
- [MED] **Consistent section chrome** — one H1 + breadcrumb + selected-project pill per section; several folded-into-settings surfaces lack a discoverable path (nav aliases exist but are indirect).
- [MED] **Brand-token audit** — enforce `_polish.scss` tokens (`--ps-accent:#00e5ff`); hard-coded colors get flagged; feature icons float free (no boxes) per project doctrine.
